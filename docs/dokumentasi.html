📋 LRS - Layanan Rencana Sistem

📌 Deskripsi Sistem

Platform e-commerce fotokopi online untuk layanan print, fotokopi, laminating, jilid, dan ATK dengan sistem pemesanan, tracking, dan pembayaran terintegrasi.

🎯 Tujuan

  • • Platform pemesanan 24/7 online
  • • Meningkatkan efisiensi layanan
  • • Transparansi harga & status real-time
  • • Manajemen inventory otomatis

👤 Fitur User

  • ✓ Browse katalog & filter
  • ✓ Kelola keranjang
  • ✓ Checkout & pembayaran
  • ✓ Tracking pesanan
  • ✓ Download invoice

🔧 Fitur Admin

  • ✓ Dashboard analytics
  • ✓ Kelola pesanan
  • ✓ CRUD produk & kategori
  • ✓ Manajemen staff
  • ✓ Laporan penjualan

⚙️ Teknologi

Backend: Laravel 10
Frontend: Tailwind CSS
Database: MySQL 8.0
Payment: QRIS & COD
