📋 Layanan Rencana Sistem (LRS)

Dokumentasi lengkap sistem Fotokopiku

📌 Deskripsi & Tujuan Sistem

Deskripsi: Fotokopiku adalah platform e-commerce untuk layanan fotokopi, print, laminating, jilid, dan penjualan ATK online dengan system pemesanan, tracking, dan pembayaran terintegrasi.

Tujuan: (1) Menyediakan platform 24/7 (2) Meningkatkan efisiensi layanan (3) Transparansi harga & status real-time (4) Memudahkan manajemen inventory & pesanan

📊 Kebutuhan Sistem

User: Registrasi, browse, filter, keranjang, checkout, tracking, invoice
Admin: Login, dashboard, kelola pesanan, CRUD produk/kategori, tracking
Database: 10 tabel, relasi 1:1 dan 1:N, indexed columns, FK constraints
Non-Fungsional: Responsive, < 2s loading, 99.5% uptime, security HTTPS

✅ Requirement Fungsional (5 FR)

FR1 Autentikasi: Registrasi, login dengan email/password, role-based access (is_admin)

FR2 Katalog: Browse produk, filter kategori, search, sort harga, detail produk

FR3 Keranjang: Add/edit/remove item, checkout, input alamat, pilih metode kirim & bayar

FR4 Pesanan: Buat order, update status, tracking lokasi, generate invoice PDF

FR5 Tracking: Status real-time (pending→diproses→selesai), lihat lokasi, riwayat pesanan

🎯 Fitur (24 total) & Teknologi

Fitur User: Registrasi, Browse, Filter, Keranjang, Checkout, Tracking, Invoice, Alamat
Fitur Admin: Login, Dashboard, Pesanan, Status, Tracking, CRUD Produk, CRUD Kategori, Staff
Backend: Laravel 10, PHP 8.2, Blade Engine
Frontend: Tailwind CSS 3, Alpine.js, Responsive
Database: MySQL 8.0, 10 tables, Indexed columns
Tools: Barryvdh PDF, QRIS/COD Payment, Laravel Breeze

📅 Timeline Implementasi (8-12 Minggu)

Fase 2 (2-3 mg): Backend - models, migrations, controllers, authentication
