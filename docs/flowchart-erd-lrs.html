1️⃣ Deskripsi Sistem & Tujuan

📌 Deskripsi Sistem

Fotokopiku adalah platform e-commerce terintegrasi yang menyediakan layanan fotokopi, print dokumen, laminating, jilid buku, dan penjualan alat tulis kantor (ATK) secara online. Sistem memfasilitasi pemesanan 24/7, tracking real-time, manajemen inventory otomatis, dan integrasi pembayaran digital (QRIS/COD) untuk meningkatkan efisiensi layanan dan kepuasan pelanggan.

🎯 Tujuan Sistem (4 Tujuan)

T1 Akses 24/7: Menyediakan platform pemesanan tanpa batasan waktu operasional
T2 Efisiensi: Meningkatkan efisiensi layanan pelanggan & manajemen pesanan
T3 Transparansi: Memberikan transparansi harga & status real-time
T4 Manajemen: Memudahkan admin mengelola inventory & laporan penjualan

2️⃣ Analisis Kebutuhan Sistem

👤 Kebutuhan User / Pelanggan

• Registrasi akun & autentikasi aman
• Browse katalog & filter kategori
• Cari produk berdasarkan nama & harga

4️⃣ Requirement Fungsional (FR)

🔐 FR1: Sistem Autentikasi & Otorisasi
User registrasi dengan email unik & password terenkripsi. Login menggunakan email/password dengan session management. Admin punya akses khusus via flag is_admin di tabel users. Role-based access control membatasi fitur admin.
🛍️ FR2: Manajemen Katalog Produk
Menampilkan produk dalam grid responsif dengan thumbnail, nama, harga, stock. Filter kategori, pencarian text, sorting harga. Setiap produk punya deskripsi detail, flag is_service (jasa/barang), status stock (tersedia/habis).
🛒 FR3: Sistem Keranjang & Checkout
User add/edit qty/remove item di keranjang. Checkout minta input nama, no WA, alamat kirim. Pilih metode kirim (Ambil Gratis / Kirim dengan ongkos). Hitung ongkir berdasarkan kota tujuan. Simpan di tabel carts & cart_items.
💳 FR4: Sistem Pembayaran & Pesanan
Pilih metode bayar: COD (bayar saat ambil) atau QRIS (scan QR, upload bukti). Sistem membuat order record dengan status 'pending'. Admin verifikasi pembayaran & ubah status ke 'diproses'. Input tracking info (lokasi, status) ke tabel order_tracks.
📍 FR5: Tracking & Notifikasi Pesanan
User lihat status pesanan real-time (pending → diproses → selesai). Tracking tampilkan lokasi & update terbaru dari order_tracks. Download invoice PDF dengan detail pesanan & total bayar. Riwayat pesanan dapat diakses kapan saja.

📚 Kolom-Kolom Penting

users: id (PK), email (UNQ), is_admin (BOOL), password, phone, photo_path

products: id (PK), category_id (FK), name, price (DECIMAL), stock (INT), is_service (BOOL)

orders: id (PK), user_id (FK), status (ENUM), payment_method, payment_status, total

order_items: id (PK), order_id (FK), product_id (FK), qty (INT), price (DECIMAL)

order_tracks: id (PK), order_id (FK), status, location, note (TEXT)

• qty: Jumlah item
