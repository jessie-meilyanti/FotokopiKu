🔗 Relasi Antar Tabel (Crow's Foot Notation)

Entitas Utama • users (1) ← → (N) orders
• users (1) ← → (1) carts
• users (1) ← → (N) addresses
• users (1) ← → (1) staff
Entitas Produk & Pesanan • categories (1) ← → (N) products
• orders (1) ← → (N) order_items
• orders (1) ← → (N) order_tracks
• products (1) ← → (N) order_items
Entitas Keranjang • carts (1) ← → (N) cart_items
• products (1) ← → (N) cart_items
Legenda Notasi • PK = Primary Key (Identitas Unik)
• FK = Foreign Key (Referensi Tabel Lain)
• UNQ = Unique (Tidak Boleh Duplikat)

📋 Layanan Rencana Sistem (LRS)

Dokumentasi lengkap sistem Fotokopiku beserta komponen, fitur, dan timeline implementasi

📌 Deskripsi Sistem

Fotokopiku adalah platform e-commerce yang menyediakan layanan fotokopi, print, laminating, jilid, dan penjualan alat tulis kantor (ATK) secara online dengan sistem pemesanan, tracking, dan pembayaran terintegrasi untuk memudahkan pelanggan mendapatkan layanan fotokopi berkualitas dengan harga kompetitif.

🎯 Tujuan Sistem

✓ Menyediakan platform pemesanan fotokopi online 24/7
✓ Meningkatkan efisiensi layanan pelanggan
✓ Memberikan transparansi harga dan status pesanan real-time
✓ Memudahkan manajemen inventory produk dan pesanan

📊Scope Sistem

User / Pelanggan

Registrasi, login, browse katalog, filter produk, keranjang belanja, checkout, pilih metode kirim, pilih pembayaran, tracking pesanan, download invoice.

Admin / Staff

Login, lihat dashboard analytics, kelola pesanan (filter, update status, tracking, invoice), kelola produk (CRUD), kelola kategori (CRUD), kelola staff.

Database

10 tabel (users, orders, products, categories, carts, cart_items, order_items, order_tracks, addresses, staff) dengan relasi one-to-many dan one-to-one.

✅Requirement Fungsional

R1: Sistem Autentikasi
User dapat registrasi dan login dengan email/password. Admin memiliki akses khusus dengan flag is_admin di tabel users.
R2: Manajemen Katalog
Menampilkan produk dengan filter kategori, pencarian, harga, dan stock. Setiap produk memiliki thumbnail, deskripsi, dan status is_service.
R3: Keranjang & Checkout
User bisa tambah/edit/hapus item di keranjang, input alamat kirim, pilih metode (COD/QRIS), hitung ongkos kirim per kota.
R4: Manajemen Pesanan
Sistem membuat pesanan dengan status tracking, admin bisa update status, tambah lokasi tracking, cetak invoice PDF.

📚 Data Dictionary - Kolom Penting

users (Pengguna)
• id: Identitas unik pengguna
• email: Email unik untuk login
• is_admin: Flag akses admin
• phone: Nomor telpon kontak
• photo_path: Path foto profil
orders (Pesanan)
• id: Nomor pesanan unik
• status: Enum (menunggu/diproses/selesai)
• payment_method: COD atau QRIS
• payment_status: Verified/Pending
• total: Total harga pesanan
products (Produk)
• id: ID produk unik
• category_id: Referensi kategori
• price: Harga (DECIMAL)
• stock: Stok barang
• is_service: Flag jasa vs barang
order_items (Item Pesanan)
• order_id: Referensi pesanan
• product_id: Referensi produk
• qty: Jumlah item
• price: Harga satuan saat pesan
• (Qty × Price = Line Total)
