📋 Layanan Referensi Sistem (LRS)

👤 Fitur User

1. Registrasi & Login
User dapat mendaftar dengan email/password dan login ke sistem untuk berbelanja
2. Browsing Katalog
Melihat daftar produk/jasa dengan fitur filter berdasarkan kategori
3. Keranjang Belanja
Menambah, mengubah jumlah, dan menghapus item dari keranjang sebelum checkout
4. Checkout
Input data pengiriman, pilih metode kirim (Ambil/Kirim Antar), dan metode pembayaran (COD/QRIS)
5. Lacak Pesanan
Melihat status pesanan real-time dengan tracking updates dari admin
6. Download Invoice
Mengunduh invoice dalam format PDF untuk setiap pesanan
7. Profil & Alamat
Mengelola data profil dan menyimpan multiple alamat pengiriman

🔧 Fitur Admin

1. Dashboard Analytics
Melihat statistik pendapatan, jumlah pesanan, dan grafik penjualan bulanan
2. Kelola Pesanan
View daftar pesanan, filter berdasarkan status, update status, tambah tracking, cetak invoice
3. Kelola Produk
CRUD produk (Tambah, Edit, Hapus) dengan upload thumbnail dan detail produk
4. Kelola Kategori
CRUD kategori produk untuk mengorganisir katalog
5. Kelola Staff
Tambah dan edit data karyawan (nama, posisi, role, gaji, foto profil)
6. Validasi Pembayaran QRIS
Menerima upload bukti transfer QRIS dari customer dan validasi pembayaran
7. Real-time Order Feed
Polling otomatis untuk melihat pesanan baru tanpa reload halaman

🗃️ Fitur Database

Users & Authentication
Pengguna dapat login dan menyimpan data profil
Products & Categories
Kelola katalog dengan relasi one-to-many kategori
Shopping Cart
Keranjang persisten per user dengan cart items
Orders & Order Items
Pesanan dengan multiple items dan status tracking
Order Tracking
Riwayat status pesanan dengan lokasi dan catatan
Staff Management
Data karyawan dengan role admin dan gaji

⚙️ Technical Stack

✅ Backend: Laravel 10 (PHP 8.2)
✅ Database: MySQL 8.0
✅ Frontend: Blade Templates + Tailwind CSS
✅ Auth: Laravel Breeze + Session
✅ Storage: Local filesystem untuk image
✅ PDF: Laravel PDF untuk invoice
